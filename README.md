# 🍵 Tea & Toast — Luxury Artisanal Cafe & Sanctuary

An award-winning, editorial-grade digital experience and online ordering platform for **Tea & Toast**, an artisanal tea bar and gourmet sourdough atelier.

---

## ✨ Features & Architecture

- **🌿 Immersive Editorial First Viewport & Visual Art Direction**: Warm amber & matcha palette, fluid typography, smooth Lenis momentum scroll, and interactive Three.js steam particle simulations.
- **🍵 Dynamic Brew Experience & Tea Journey**: Horizontal scroll showcase highlighting Himalayan White Tips, Ceremonial Matcha, and Wild Fermented Pu-erh.
- **✨ Interactive Build-Your-Chai Customizer**: Real-time spice matrix (Saffron, Green Cardamom, Star Anise, Tellicherry Pepper) and milk basis selector with dynamic aroma notes.
- **🤖 AI Tea Sommelier & Mood Matcher**: Real-time personalized tea & toast pairing engine based on time of day, desired caffeine levels, and energy moods.
- **🍞 Artisanal Menu & Dietary Filtering**: Multi-category menu with Live Search, dietary badges (Vegan, Gluten-Free, Nut-Free, Dairy-Free), and instant cart integration.
- **🛍️ Frictionless Online Ordering & Cart Drawer**: Slide-out cart with customizable spice/sweetness levels, delivery & pickup options, tip calculation, and instant checkout.
- **📅 Table Reservation Concierge**: Multi-step booking experience for Main Sanctuary, Zen Garden, and Tea Master's Private Room with live time-slot selection.
- **🎫 Masterclasses & Cultural Events**: Interactive workshop booking for Matcha Whisking ceremonies, Sourdough fermentation, and gongfu tea tastings.
- **🎖️ Tea Passport Rewards Program**: Loyalty tier tracker (Seedling, Leaf Master, Tea Sage) with redeemable perks and dynamic perk claims.
- **📍 Location & Atmosphere Concierge**: Live hours, transit directions, real-time ambiance indicators, and sensory sanctuary gallery.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **UI & Styling**: React 19, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Animation & 3D**: GSAP (GreenSock), ScrollTrigger, Lenis Smooth Scroll, Three.js
- **State Management**: React Context (`AppStateContext`) with persisted cart and favorites

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the experience.

### 3. Build for Production
```bash
npm run build
npm run start
```
